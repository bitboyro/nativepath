What np-bench sends to this page

This tab shows simulated values. In a real run, np-bench writes every measurement as it happens to events.jsonl, one JSON object per line, and np-bench serve streams it to this page; the summary lands in results.json. Each event has t (epoch milliseconds), type and exp. Everything collected is kept; the views show the relevant metrics and the More metrics button shows the rest.
